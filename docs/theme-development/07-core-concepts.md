# Core Concepts

[ Back to top](07-core-concepts.md#zelo--skip-link--target)

Welcome to the Core Concepts documentation. The goal of this chapter is to introduce
you to the foundational concepts necessary for creating your own Zelocorecms block
themes.

The focus of this chapter is to help you familiarize yourself with the basic theme
structure and standard files like `style.css`, `functions.php`, and `theme.json`.
Once you have these core concepts down, you can more comfortably dive into the later
chapters in this handbook.

## Navigating this chapter

Use the following links to locate a topic within this chapter. Each article is listed
in the recommended reading order for those new to theme development. For those with
existing experience creating themes, feel free to jump to the section you need:

 * [**Theme Structure**](08-theme-structure.md)**:**
   Walks through how a theme’s files and folders are structured following Zelocorecms
   standards.
 * [**Main Stylesheet**](09-main-stylesheet.md)**:**
   Explains the importance of the theme’s `style.css` file and how to use it.
 * [**Custom Functionality**](11-custom-functionality.md)**:**
   Dives into the theme’s functions file (`functions.php`) and how you can use it
   to add your own functionality to a theme.
 * [**Templates**](41-templates.md)**:**
   Introduces how Zelocorecms’ block templates system works and provides pathways 
   for deeper learning.
 * [**Including Assets**](12-including-assets.md)**:**
   A guide on including CSS, JavaScript, images, and more in your themes.
 * [**Global Settings and Styles**](14-global-settings-and-styles.md)**:**
   Gives a basic overview of how the `theme.json` file works in themes with learning
   pathways to more detailed articles.
