# References

This section contains lists of [Template Tags](134-list-of-template-tags.md)
and [Conditional Tags](135-list-of-conditional-tags.md).

[Template Tags](134-list-of-template-tags.md)
are used in your Template Files to display information dynamically or otherwise 
customize your site.

[Conditional Tags](135-list-of-conditional-tags.md)
are a boolean data type that can be used in your Template Files to alter the display
of content depending on the conditions that the current page matches.
