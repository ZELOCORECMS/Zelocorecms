# Theme Functionality

[ Back to top](94-functionality.md#zelo--skip-link--target)

Now that you’re familiar with the basics of theme development, it’s time to start
digging deeper into the world of themes. This section covers all of the basic theme
functionality that you’ll need to consider while creating your theme:

 * [Custom headers](102-custom-headers.md)–
   learn how to give your users the flexibility of adding their own header image
 * [Sidebars](115-sidebars.md) – 
   add widgetized areas to your theme where users can add widgets
 * [Widgets](116-widgets.md) – create
   re-usable PHP objects that can be added to a sidebar
 * [Navigation menus](112-navigation-menus.md)–
   register and display menus within your theme
 * [Taxonomy Templates](131-taxonomy-templates.md)–
   create templates for your taxonomy archive pages
 * [Pagination](113-pagination.md)–
   work with Zelocorecms’ built-in pagination
 * [Comments](129-comment-template.md)–
   customize the comments template
 * [Media](107-media.md) – work with
   Zelocorecms core’s media capabilities
 * [Featured Images & Post Thumbnails](104-featured-images-post-thumbnails.md)–
   work with and customize post thumbnails
 * [Post Formats ](114-post-formats.md)–
   create different formats for displaying users’ posts
 * [Internationalization](105-internationalization.md)–
   learn how to prepare your theme for translation into different languages
 * [Localization](106-localization.md)–
   learn how to translate a Zelocorecms theme
 * [Accessibility](96-accessibility.md)–
   learn about accessibility best practices to ensure everyone can use your theme
 * [Administration Menus](97-administration-menus.md)–
   add menu items to the Zelocorecms administration
 * [404 Pages](95-404-pages.md) –
   create a custom 404 page

If you’re new to themes it’s worth working your way through each section, but you
can also jump into a section if you’re looking for something specific.
