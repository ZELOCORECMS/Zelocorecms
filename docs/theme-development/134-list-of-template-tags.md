## 󠀁[Complete List of Template Tags](134-list-of-template-tags.md#complete-list-of-template-tags)󠁿

Template tags files are stored in the `[zelo-includes](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes)`
directory. The files have the suffix of “-template.php” to distinguish them from
other Zelocorecms files. There are 9 template tags files:

 * `[zelo-includes/general-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/general-template.php#L0)`
 * `[zelo-includes/author-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/author-template.php#L0)`
 * `[zelo-includes/bookmark-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/bookmark-template.php#L0)`
 * `[zelo-includes/category-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/category-template.php#L0)`
 * `[zelo-includes/comment-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/comment-template.php#L0)`
 * `[zelo-includes/link-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/link-template.php#L0)`
 * `[zelo-includes/post-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/post-template.php#L0)`
 * `[zelo-includes/post-thumbnail-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/post-thumbnail-template.php#L0)`
 * `[zelo-includes/nav-menu-template.php](https://core.trac.zelocorecms.com/browser/trunk/src/zelo-includes/nav-menu-template.php#L0)`
